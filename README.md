# GNU Octave-MatLab

Uso do software "GNU Octave/MatLab" para codificação de exercícios de Matemática Computacional 💻!!!

Usarei este repositório para publicar todos os exercícios da disciplina de Matemática Computacional do semestre 2/2026, separados por semanas, sendo que a semana (1) será de uso livre, ou seja, terá algoritmos diversos codificados por meio do GNU Octave.👨‍💻

Além disso, espero que este repositório sirva de exemplo para transmitir conhecimento e para cessar quaisquer dúvidas quanto ao uso do Octave para resolução de exercícios de Matemática Computacional.📚📖
